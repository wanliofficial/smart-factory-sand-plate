# 参考图视觉验收标准

本项目中的三台设备必须以用户提供的三张参考图作为**造型与线框密度基准**，而不是简单的低模方块。

## 机器狗

- 采用高密度曲面线框，而不是纯 Box 组合。
- 背部、头部、颈部要有连续经纬向拓扑线。
- 四条腿必须是明确的三段式机械结构：髋关节、膝关节、踝关节。
- 关节需要有圆形机械环和局部加密线。
- 头部必须有明显的双传感器/双眼视觉细节。
- 整体轮廓接近工业四足机器人，避免卡通狗或动物形态。

## 无人机

- 必须是现代四旋翼工业无人机轮廓。
- 四个电机位置均有双层/多层圆形旋翼线框。
- 每个旋翼圆环需要大量径向/网格线，不能只画一个圆。
- 中央机身为矩形/流线组合结构。
- 下方必须有明显的三轴云台和圆形镜头。
- 正面镜头是视觉焦点之一。

## 无人车

- 必须是现代自动驾驶乘用车，而不是简单长方体汽车。
- 车身采用密集三角网格/曲面线框。
- 车顶有明显 LiDAR / Sensor Pod。
- 四个轮胎、轮毂和轮辐均需要线框细节。
- 前脸具有青蓝色发光灯带。
- 车周围增加橙色 LiDAR/Radar 扫描弧线/数据点，形成参考图中的冷暖对比。

## 总体风格

- 黑/深蓝背景。
- 设备主体使用青蓝/白蓝色细线。
- 发光元素通过 Bloom 形成柔和光晕，但主体轮廓仍然清晰。
- 设备不能出现实心材质、纹理贴图或照片质感；核心视觉始终是“数字孪生线框”。
- 线框密度应足以在设备靠近镜头时仍保持工程 CAD / 数字孪生模型的感觉。
